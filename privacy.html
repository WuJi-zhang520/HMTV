隐私政策

最后更新：2026-11-23

一、我们收集与保存的信息

1. 站点配置地址：仅保存您自己填写的配置地址，用于下次启动时直接加载站点列表。

2. 网盘授权 Token：仅在您主动登录第三方网盘并授权后读取，用于向对应网盘发起 API 请求。Token 经系统密钥（HUKS）加密后仅保存在本机，不以明文存储。

3. 媒体服务器地址与账号信息：仅在您主动添加媒体服务器（Emby / Jellyfin / 飞牛 / Alist / WebDAV）时保存，用于连接对应服务器；密码同样加密保存在本机。

4. 播放历史、收藏、界面偏好：保存于本机，用于内容续播与个性化展示。

5. 运行日志：解析与播放的排障信息，仅写本机，您可随时清空或导出。

二、数据是否上传服务器

以上所有数据均仅保存在您的本机设备，本应用不向任何自建或第三方服务器上传上述数据。

所有请求由您的设备直接发起：读取您填写的配置地址、加载该配置里影片的封面与播放地址；网盘与媒体服务器请求直接与对应官方服务通信。

系统备份已排除凭证数据：换机恢复后需重新登录网盘与媒体服务器。

三、权限说明

本应用申请的权限仅用于：联网播放（INTERNET）、播放时滑动调节媒体音量（ACCESS_NOTIFICATION_POLICY、MODIFY_AUDIO_SETTINGS）、切换栏目时的轻触振动反馈（VIBRATE）。

本应用不读取通讯录、短信、相册、位置等隐私内容，也不采集设备标识。

四、数据删除

您可在「设置 - 缓存管理 / 运行日志」中清除本机数据，在“我的云盘”中断开登录以清除对应凭证；卸载本应用将清除本地保存的全部数据。
